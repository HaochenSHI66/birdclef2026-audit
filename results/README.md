# Results artifacts

Every number in the paper traces to one of these JSON files. Generated by the `src/` scripts; see
[../REPRODUCE.md](../REPRODUCE.md).

| file | what it holds |
|---|---|
| `b2_final.json` | **Headline.** 8-cell de-biased held-out oracle-headroom + TOST(δ=0.01) + calibrated soft-fusion, author-clustered bootstrap (n_boot=1000, n_null=50). |
| `b2_results.json` | Earlier 3-model / 6-cell run (mis-centered null); superseded by `b2_final.json`, kept for transparency. |
| `pooled_auc_compare.json` | Per-model pooled macro-AUC on the common 197-class mask + per-seed spread. |
| `coverage_audit.json` | eBird coverage wall: 203/234 mapped (158 exact + 45 sci-name), 31 unmapped (25 insect morphospecies + 6 absent taxa). |
| `domain_shift.json` | Perch focal→soundscape macro-AUC (0.9283→0.7367), per-class drops, embedding MMD². |
| `supp_robustness_full.json` | Perch-vs-CNN/PANN/BEATs robustness gap (re-trained checkpoints). Supersedes the "infeasible" note in `domain_shift.json`. |
| `add_robustness_gap.json` | CNN-only robustness gap detail (matched-class). |
| `postproc_ablation.json` | Post-processing ablation (taxonomy / cross-taxa / spatial) on the clean baseline — null result. |
| `cv_lb_concordance.json` | CV↔LB rank concordance (n=3 reproducible; sanity check only). |
| `supp_nestedcv.json` | Nested-CV corroboration of the headline (single-seed base OOF). |
| `supp_stats` / `supp_deepstats.json` / `supp_repsplits.json` / `supp_reviewer.json` | Statistical hardening: repeated random splits, leave-one-author, multiplicity control. |
| `supp_selector.json` / `supp_frozen_transfer.json` | Selector diagnostics and frozen selector/fusion transfer under shift. |
| `supp_coverage_ceiling.json` | Coverage-ceiling analysis (upper bound if unmapped classes were perfectly handled). |
| `add_zs_vs_lp.json` | Zero-shot vs linear-probe paradox analysis. |
| `add_failure_anatomy.json` / `add_exclusion.json` / `add_postproc_anchordep.json` | Failure anatomy, exclusion tests, post-proc anchor-dependence. |
| `add_pseudolabel_audit.json` | Pseudo-label headroom audit (null, ΔAUC +0.0015, CI ⊇ 0). |
| `beats_merge_report.json` | BEATs OOF merge bookkeeping. |
